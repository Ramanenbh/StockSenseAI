This is a project that I am building on my own for my own exploration of **Generative AI and Langgraph** to build a stock information
aggregator that I can use for my own trading use. 
The app is hosted on streamlit _UI https://stocksensee-ai.streamlit.app/_, where given a US stock ticker and question it can pull relevant latest information & actionables. I shall slowly update the current features implemented.

**Tasks Completed thus far:**
1. Internet Search Tool
2. News Handling
3. Streamlit Frontend UI & Progress Logging
4. User Validation if user keys invalid query & Retry

**Tasks to do:**

5. Add in a MCP server for certain further actions.

**Output:**
QUERY: NVDA's latest earnings
